# Licencia comercial

Gestión Comercial se distribuye bajo **GNU Affero General Public License v3.0
(AGPL-3.0)**. Ver [LICENSE](LICENSE).

La AGPL es una licencia de código abierto con copyleft fuerte: permite usar,
estudiar, modificar y redistribuir el software, incluso con fines comerciales,
siempre que se cumplan sus condiciones. La más relevante para un sistema web es
la **sección 13**: si se modifica el programa y se pone a disposición de usuarios
a través de una red, hay que ofrecerles el código fuente de esa versión.

## Cuándo necesitas una licencia comercial

La AGPL cubre la mayoría de los usos. Una licencia comercial es necesaria
cuando quieres alguna de estas cosas sin asumir las obligaciones de la AGPL:

| Escenario | ¿Requiere licencia comercial? |
|---|---|
| Usar el sistema internamente en tu negocio | No |
| Modificarlo y usarlo en tu propia operación | No (sin obligación de publicar si no lo expones en red) |
| Ofrecerlo como servicio a terceros y publicar tu código | No |
| Ofrecerlo como servicio a terceros sin publicar tus modificaciones | **Sí** |
| Integrarlo en un producto de software propietario | **Sí** |
| Distribuirlo como marca blanca o solución empaquetada | **Sí** |
| Usar el nombre o el logo del proyecto | **Sí**, requiere autorización escrita |

## Qué incluye la licencia comercial

- Derecho de uso, modificación y distribución sin las obligaciones de copyleft
  de la AGPL.
- Derecho a integrarlo en productos o servicios de código cerrado.
- Derecho a ofrecerlo como servicio sin publicar el código modificado.
- Condiciones y alcance definidos por contrato.

La licencia comercial no transfiere la titularidad del código ni el derecho de
uso de la marca.

## Modelo de doble licencia

Este esquema se conoce como *dual licensing*. Es el mismo modelo que usan
proyectos como Grafana, MongoDB o Nextcloud: el código permanece abierto y
auditable, y quien necesita condiciones distintas compra una licencia.

El titular del copyright puede ofrecer licencias adicionales porque conserva la
titularidad. Las contribuciones de terceros se aceptan bajo los mismos términos,
salvo acuerdo escrito distinto.

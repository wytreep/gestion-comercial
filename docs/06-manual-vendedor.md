# 06 · Manual del vendedor

Este manual describe la operación diaria de quien vende y cobra.

## Qué puedes ver

Tu cuenta está limitada a la operación comercial:

| Puedes ver | No puedes ver |
|---|---|
| Panel operativo | Finanzas |
| Ventas | Caja |
| Cartera | Reportes |
| Clientes | Compras |
| Productos y precios de venta | Costos y márgenes |
| Stock | Utilidades |
| Alertas | Administración y respaldos |

El sistema no te muestra el costo de la mercancía ni la ganancia del negocio.
Tampoco puedes registrar compras, eliminar ventas, cambiar precios ni ajustar
stock.

## Tu panel

Al iniciar sesión ves un resumen pensado para vender:

| Indicador | Qué significa |
|---|---|
| Ventas del mes | Total vendido en el mes |
| Cobrado en el mes | Pagos recibidos |
| Cartera pendiente | Lo que falta por cobrar |
| Ticket promedio | Venta media por pedido |

También encuentras:

- **Últimas ventas** con estado de pago y de pedido.
- **Stock disponible** con precio de venta.
- **Accesos rápidos** a nueva venta, clientes, cartera y ventas.

## Registrar una venta

1. Pulsa **Nueva venta**.
2. Busca el cliente por nombre o teléfono.
   - Si no existe, escríbelo como cliente nuevo.
3. Agrega los productos y las cantidades.
4. Revisa precios y total.
5. Define el abono inicial.
   - Si no hay abono, el saldo queda en cartera.
6. Pulsa **Registrar venta**.

La venta aparece de inmediato en el historial y, si queda saldo, en cartera.

### Estados de pago

| Estado | Significado |
|---|---|
| `pagado` | Sin saldo pendiente |
| `abono` | Pago parcial |
| `pendiente` | Sin pagos |
| `fiado` | Crédito con fecha límite |

### Estados del pedido

| Estado | Significado |
|---|---|
| `nuevo` | Recién registrado |
| `en_preparacion` | En alistamiento |
| `entregado` | Entregado al cliente |
| `cancelado` | Anulado |

## Editar una venta

Puedes corregir una venta desde el historial:

1. Entra a **Ventas**.
2. Pulsa el botón de edición.
3. Ajusta cliente, productos, cantidades o estado del pedido.
4. Guarda los cambios.

No puedes eliminar ventas. Si hay un error grave, pide apoyo a administración.

## Cobrar un abono

1. Entra a **Ventas** o **Cartera**.
2. Ubica la venta o el cliente con saldo.
3. Pulsa **Abonar**.
4. Escribe el monto.
5. Selecciona medio de pago:
   - Efectivo
   - Transferencia
6. Selecciona destino:
   - Caja (efectivo)
   - Nequi
   - Daviplata
   - Bancolombia App
   - Banco
   - Otro
7. Agrega referencia o notas si aplica.
8. Guarda el pago.

El saldo se actualiza automáticamente.

## Clientes

En **Clientes** puedes:

- Consultar el listado.
- Crear un cliente nuevo.
- Editar datos de contacto.

Recomendaciones:

- Registra el teléfono correcto.
- Usa nombres claros y consistentes.
- Evita duplicados.
- Anota direcciones útiles para entrega.

## Productos y stock

En **Productos** ves:

- Nombre y categoría.
- Unidad de venta.
- Precio de venta.
- Stock disponible.

No ves el precio de compra ni el margen. Si necesitas un cambio de precio,
solicítalo a administración.

En **Stock** puedes consultar el historial de entradas y salidas:

- Positivo = entrada.
- Negativo = salida.

## Cartera

En **Cartera** ves los clientes con saldo pendiente:

| Columna | Significado |
|---|---|
| Cliente | Nombre |
| Teléfono | Contacto |
| Pedidos | Ventas con saldo |
| Total ventas | Facturado al cliente |
| Total pagado | Abonos recibidos |
| Saldo | Deuda pendiente |

Prioriza los saldos más antiguos y confirma siempre el pago antes de registrar.

## Alertas

Las alertas te avisan de:

- Deudas vencidas.
- Stock bajo.
- Avisos del sistema.

Revísalas al iniciar el día y antes de cerrar la jornada.

## Rutina diaria sugerida

### Al iniciar

1. Revisa alertas.
2. Consulta stock disponible.
3. Revisa cartera vencida.
4. Confirma precios vigentes.

### Durante el día

1. Registra cada venta al momento.
2. Registra abonos inmediatamente.
3. Verifica que el saldo coincida con lo recibido.
4. Anota referencias de transferencias.

### Al cerrar

1. Revisa las ventas del día.
2. Confirma los pagos registrados.
3. Revisa la cartera nueva.
4. Informa novedades a administración.

## Errores frecuentes

| Situación | Qué hacer |
|---|---|
| No aparece un cliente | Créalo desde el formulario de venta o en Clientes |
| El saldo no cuadra | Revisa los abonos registrados en la venta |
| No puedes eliminar una venta | Es una acción exclusiva de administración |
| No ves costos ni utilidades | Es correcto: tu rol no incluye información financiera |
| No puedes ajustar stock | Solicítalo a administración |

## Seguridad

- No compartas tu contraseña.
- Cierra sesión al terminar.
- No dejes la sesión abierta en equipos compartidos.
- Reporta cualquier acceso extraño.
